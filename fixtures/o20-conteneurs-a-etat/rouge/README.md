# Produit d'exemple — fixture ROUGE O-20 (TF-1986), valeurs inventées

Le moteur de traitement photogrammétrique tourne dans un conteneur local. Pour le relancer après
un redémarrage du poste, la commande docker start suffit : cette phrase n'est pas une commande, et
O-20 ne la lit pas.

## Relancer le moteur

```bash
docker start nodeodm
```

La commande qui a créé ce conteneur n'est écrite nulle part : c'est le fait du 24/10/2026.
